# LanChat 数据库设计文档

> 文档版本：v3.0 | 更新日期：2026-07-31 | 状态：✅ 已完成

---

## 一、技术选型

- **数据库**：SQLite（better-sqlite3 同步驱动）
- **存储路径**：`{userData}/LanChat/lanchat.db`（自动创建，无需手动配置）
- **选型理由**：
  - 零配置：不需要安装 MySQL/PostgreSQL
  - 单文件：一个 .db 文件包含全部数据
  - 同步 API：better-sqlite3 比异步驱动快 2-10 倍
  - 适合桌面应用：数据量小，无并发问题

## 二、表结构

### 1. chat_history（聊天记录）

```sql
CREATE TABLE IF NOT EXISTS chat_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_ip TEXT NOT NULL,
    device_name TEXT DEFAULT '未知设备',
    content TEXT,
    content_type TEXT DEFAULT 'text',
    is_self INTEGER DEFAULT 0,
    thumbnail_path TEXT,
    image_path TEXT,
    image_size INTEGER,
    image_width INTEGER,
    image_height INTEGER,
    is_read INTEGER DEFAULT 0,
    message_id TEXT UNIQUE,
    status TEXT NOT NULL DEFAULT 'sent',
    created_at TEXT DEFAULT (datetime('now', 'localtime'))
);
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER | 自增主键 |
| `device_ip` | TEXT | 对方设备 IP（本表的核心查询条件） |
| `device_name` | TEXT | 对方设备名称 |
| `content` | TEXT | 消息内容（文字 OR 图片相对路径） |
| `content_type` | TEXT | `'text'` / `'image'` |
| `is_self` | INTEGER | 1 = 自己发的，0 = 对方发的 |
| `thumbnail_path` | TEXT | 缩略图路径 |
| `image_path` | TEXT | 图片文件相对路径 |
| `image_size` | INTEGER | 图片文件字节数 |
| `image_width` | INTEGER | 图片宽度 |
| `image_height` | INTEGER | 图片高度 |
| `is_read` | INTEGER | 是否已读（1/0） |
| `message_id` | TEXT UNIQUE | ⭐ 业务唯一 ID（UUID），用于状态跟踪和去重 |
| `status` | TEXT | ⭐ 消息状态：`'sent'`（已发送）/ `'pending'`（待发送）/ `'failed'`（发送失败） |
| `created_at` | TEXT | 创建时间（ISO 格式） |

**索引**：
```sql
CREATE INDEX IF NOT EXISTS idx_chat_device_ip ON chat_history(device_ip);
CREATE INDEX IF NOT EXISTS idx_chat_message_id ON chat_history(message_id);
```

### 2. config（配置项）

```sql
CREATE TABLE IF NOT EXISTS config (
    key TEXT PRIMARY KEY,
    value TEXT
);
```

**用途**：Key-Value 键值对存储（当前只存 `user_name`）

| key | value |
|-----|-------|
| `user_name` | 本机用户显示名称 |

### 3. contacts（联系人）

```sql
CREATE TABLE IF NOT EXISTS contacts (
    device_ip TEXT PRIMARY KEY,
    device_name TEXT DEFAULT '未知设备',
    last_message TEXT,
    last_time TEXT DEFAULT (datetime('now', 'localtime')),
    unread_count INTEGER DEFAULT 0
);
```

**用途**：最近联系人列表（主页左侧显示）

| 字段 | 说明 |
|------|------|
| `device_ip` | 对方 IP（主键） |
| `device_name` | 对方设备名 |
| `last_message` | 最后一条消息摘要 |
| `last_time` | 最后通信时间 |
| `unread_count` | 未读消息数 |

## 三、DAO 函数接口

```javascript
// ===== chat_history =====
insertMessage(msg)              // 插入消息（content_type/status/imagePath 等）
updateMessageStatus(msgId, status)  // 更新消息状态（pending→sent/failed）
getPendingMessages(deviceIp)    // 获取待重发的消息（status='pending' 或 'failed'）
deleteMessage(messageId)        // 按 message_id 删除

// 分页查询（旧版，保留兼容）
getChatHistory(deviceIp, page, pageSize)  // page=1 最新，page=2 次新...
// 全量查询（新版，推荐使用）
getAllMessages(deviceIp)        // 返回该设备的全部消息（按 created_at ASC）

// ===== 联系人 =====
upsertContact(contact)          // 插入或更新联系人
getRecentContacts()             // 最近联系人列表（按 last_time DESC）
getUnreadCount(deviceIp)        // 获取未读数
markAsRead(deviceIp)            // 全部标记已读
clearUnread(deviceIp)           // 清零未读计数

// ===== 配置 =====
getConfig(key, defaultValue)    // 获取配置
setConfig(key, value)           // 设置配置
```

## 四、消息生命周期

```
用户点击发送
    │
    ▼
insertMessage({ status: 'pending', message_id: 'uuid-xxx' })
    │
    ▼
TCP.sendMessage() ──成功──► updateMessageStatus(id, 'sent')
    │
    失败
    │
    ▼
updateMessageStatus(id, 'failed')
    │
    ▼ (对方上线)
retryPendingMessages(deviceIp)
    │
    ▼
逐一 TCP.sendMessage()
    │
    成功 → updateMessageStatus(id, 'sent') → on:retry-completed
    失败 → updateMessageStatus(id, 'failed') → 等待下次重试
```

**状态流转**：`pending → sent` / `pending → failed → ... retry → sent`

## 五、图片存储策略

图片文件保存到 `{userData}/LanChat/images/`：

```
{userData}/LanChat/images/
├── paste_20260731_120000.jpg    # 粘贴的图片
├── send_20260731_130000.png     # 选择发送的图片
└── recv_20260731_140000.jpg     # 收到的图片
```

- 数据库 `image_path` 存**相对路径**（如 `images/send_xxx.jpg`）
- 前端通过 `invoke:get-image-path` 获取完整路径
- **不存 base64**：base64 比二进制大 33%，全部存文件
