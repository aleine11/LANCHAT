# LanChat 数据库设计文档

> 版本：V1.0 | 日期：2026-07-30 | 数据库：SQLite 3

---

## 一、数据库基本信息

| 项目 | 说明 |
|------|------|
| 数据库类型 | SQLite 3（嵌入式数据库） |
| 存储位置 | `{用户AppData}/LanChat/lanchat.db` |
| 字符编码 | UTF-8 |
| 特点 | 无需安装、单文件存储、适合桌面应用 |
| ORM工具 | better-sqlite3（Node.js 同步驱动，性能极高） |

> **大白话**：SQLite 就像一个迷你Excel文件，存在你电脑上，不需要额外装数据库软件。聊天记录全存在这个 `.db` 文件里。

---

## 二、数据表清单

| 序号 | 表名 | 用途 | 类型 |
|------|------|------|------|
| 1 | `chat_history` | 聊天消息记录 | 核心业务表 |

## 三、表结构详细设计

### 3.1 表：`chat_history`（聊天记录表）

**用途**：存储所有收发消息，包括文字和图片消息。

| 序号 | 字段名 | 数据类型 | 长度 | 是否为空 | 默认值 | 主键 | 自增 | 注释说明 |
|------|--------|----------|------|----------|--------|------|------|----------|
| 1 | `id` | INTEGER | — | NOT NULL | — | ✅ 主键 | ✅ 自增 | 消息唯一ID |
| 2 | `device_ip` | TEXT | 45 | NOT NULL | — | | | 对方设备IP地址（用于索引聊天记录） |
| 3 | `device_name` | TEXT | 50 | NOT NULL | — | | | 对方设备显示名称（冗余存储，方便查询） |
| 4 | `content` | TEXT | — | NOT NULL | — | | | 消息内容：文字消息存文字，图片消息存相对路径 |
| 5 | `content_type` | TEXT | 10 | NOT NULL | 'text' | | | 消息类型：`text` = 文字，`image` = 图片 |
| 6 | `is_self` | INTEGER | — | NOT NULL | 0 | | | 消息方向：`0` = 收到的（对方发来），`1` = 发出的（自己发出） |
| 7 | `thumbnail_path` | TEXT | 500 | NULL | NULL | | | 缩略图本地路径（仅图片消息，用于聊天界面快速显示） |
| 8 | `image_path` | TEXT | 500 | NULL | NULL | | | 原始图片本地路径（仅图片消息） |
| 9 | `image_size` | INTEGER | — | NULL | NULL | | | 图片文件大小，单位字节（仅图片消息） |
| 10 | `image_width` | INTEGER | — | NULL | NULL | | | 图片宽度像素（仅图片消息） |
| 11 | `image_height` | INTEGER | — | NULL | NULL | | | 图片高度像素（仅图片消息） |
| 12 | `is_read` | INTEGER | — | NOT NULL | 0 | | | 是否已读：`0`=未读，`1`=已读 |
| 13 | `message_id` | TEXT | 36 | NOT NULL | — | | | 消息全局ID（UUID格式，用于去重） |
| 14 | `created_at` | TEXT | 25 | NOT NULL | — | | | 消息发送时间（ISO 8601格式） |

**索引设计：**

| 索引名 | 类型 | 字段 | 用途 |
|--------|------|------|------|
| `idx_chat_device_ip` | 普通索引 | `device_ip` | 按设备查询聊天记录 |
| `idx_chat_created_at` | 普通索引 | `created_at` | 按时间排序消息 |
| `idx_chat_device_time` | 联合索引 | `device_ip, created_at` | 查询某设备聊天记录并排序 |
| `uq_chat_message_id` | 唯一索引 | `message_id` | 防止消息重复存储 |

**建表SQL：**
```sql
CREATE TABLE IF NOT EXISTS chat_history (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    device_ip       TEXT    NOT NULL,
    device_name     TEXT    NOT NULL,
    content         TEXT    NOT NULL,
    content_type    TEXT    NOT NULL DEFAULT 'text',
    is_self         INTEGER NOT NULL DEFAULT 0,
    thumbnail_path  TEXT    NULL,
    image_path      TEXT    NULL,
    image_size      INTEGER NULL,
    image_width     INTEGER NULL,
    image_height    INTEGER NULL,
    is_read         INTEGER NOT NULL DEFAULT 0,
    message_id      TEXT    NOT NULL,
    created_at      TEXT    NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_chat_device_ip 
    ON chat_history(device_ip);

CREATE INDEX IF NOT EXISTS idx_chat_created_at 
    ON chat_history(created_at);

CREATE INDEX IF NOT EXISTS idx_chat_device_time 
    ON chat_history(device_ip, created_at);

CREATE UNIQUE INDEX IF NOT EXISTS uq_chat_message_id 
    ON chat_history(message_id);
```

**示例数据：**

| id | device_ip | device_name | content | content_type | is_self | is_read | message_id | created_at |
|----|-----------|-------------|---------|-------------|---------|---------|------------|------------|
| 1 | 192.168.1.3 | 小红的电脑 | 你好，在吗？ | text | 0 | 1 | abc-123 | 2026-07-30T10:30:00 |
| 2 | 192.168.1.3 | 小红的电脑 | 在的，什么事？ | text | 1 | 1 | def-456 | 2026-07-30T10:30:15 |
| 3 | 192.168.1.3 | 小红的电脑 | ./images/img_001.jpg | image | 0 | 0 | ghi-789 | 2026-07-30T10:31:00 |

### 3.2 表：`config`（系统配置表）

**用途**：存储用户个人设置，键值对形式。

| 序号 | 字段名 | 数据类型 | 长度 | 是否为空 | 默认值 | 主键 | 注释说明 |
|------|--------|----------|------|----------|--------|------|----------|
| 1 | `key` | TEXT | 100 | NOT NULL | — | ✅ 主键 | 配置项键名 |
| 2 | `value` | TEXT | 1000 | NOT NULL | — | | 配置项值 |
| 3 | `updated_at` | TEXT | 25 | NOT NULL | — | | 最后更新时间 |

**系统预置配置项：**

| key | 默认 value | 说明 |
|-----|-----------|------|
| `user_name` | `用户-{计算机名}` | 用户自定义的显示名称 |
| `theme_color` | `#409EFF` | 主题色（后期支持自定义） |
| `theme_mode` | `light` | 主题模式：`light` 或 `dark`（后期扩展） |
| `udp_port` | `5678` | UDP设备发现端口 |
| `tcp_port` | `5679` | TCP聊天端口 |
| `auto_start` | `false` | 是否开机自启（后期扩展） |
| `notification_enabled` | `true` | 是否开启新消息通知 |
| `sound_enabled` | `true` | 是否开启消息提示音（后期扩展） |

**建表SQL：**
```sql
CREATE TABLE IF NOT EXISTS config (
    key         TEXT PRIMARY KEY,
    value       TEXT NOT NULL,
    updated_at  TEXT NOT NULL
);
```

### 3.3 表：`contacts`（联系人表）

**用途**：记录所有聊过天的设备信息，相当于"通讯录"。

| 序号 | 字段名 | 数据类型 | 长度 | 是否为空 | 默认值 | 主键 | 注释说明 |
|------|--------|----------|------|----------|--------|------|----------|
| 1 | `device_ip` | TEXT | 45 | NOT NULL | — | ✅ 主键 | 设备IP地址 |
| 2 | `device_name` | TEXT | 50 | NOT NULL | — | | | 设备显示名称 |
| 3 | `hostname` | TEXT | 100 | NULL | NULL | | | 计算机主机名 |
| 4 | `last_message` | TEXT | 200 | NULL | NULL | | | 最后一条消息摘要 |
| 5 | `last_message_time` | TEXT | 25 | NULL | NULL | | | 最后一条消息时间 |
| 6 | `unread_count` | INTEGER | — | NOT NULL | 0 | | | 未读消息数 |
| 7 | `is_blocked` | INTEGER | — | NOT NULL | 0 | | | 是否拉黑：`0`=正常，`1`=已拉黑（后期扩展） |
| 8 | `first_contact_at` | TEXT | 25 | NOT NULL | — | | | 第一次聊天时间 |
| 9 | `updated_at` | TEXT | 25 | NOT NULL | — | | | 最后更新时间 |

**索引设计：**

| 索引名 | 类型 | 字段 | 用途 |
|--------|------|------|------|
| `idx_contacts_time` | 普通索引 | `last_message_time` | 按最近聊天时间排序 |

**建表SQL：**
```sql
CREATE TABLE IF NOT EXISTS contacts (
    device_ip         TEXT PRIMARY KEY,
    device_name       TEXT NOT NULL,
    hostname          TEXT NULL,
    last_message      TEXT NULL,
    last_message_time TEXT NULL,
    unread_count      INTEGER NOT NULL DEFAULT 0,
    is_blocked        INTEGER NOT NULL DEFAULT 0,
    first_contact_at  TEXT NOT NULL,
    updated_at        TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_contacts_time 
    ON contacts(last_message_time DESC);
```

## 四、表关系说明

```
┌──────────┐          ┌──────────────┐
│ contacts │          │ chat_history │
├──────────┤          ├──────────────┤
│ device_ip│◄─────────│ device_ip    │  (一对多：一个联系人有多条聊天记录)
│          │          │              │
└──────────┘          └──────────────┘

┌──────────┐
│ config   │  (独立配置表，存用户自己的设置)
└──────────┘
```

- `contacts` 和 `chat_history`：**一对多关系**，通过 `device_ip` 关联。查询时不需要 JOIN，直接根据 `device_ip` 查历史记录即可。
- 设计上采用**适度冗余**：`chat_history` 表中冗余存储 `device_name`，避免每次查消息都要关联 contacts 表。

---

## 五、数据库设计原则

1. **轻量优先**：SQLite 单文件数据库，不需要单独安装
2. **适度冗余**：聊天记录中冗余存储设备名，减少关联查询
3. **索引优化**：按设备IP和时间建立联合索引，保证聊天记录查询速度
4. **消息去重**：`message_id` 唯一索引防止网络重传导致的消息重复
5. **本地存储**：所有数据存本地，不涉及云端，保护隐私
6. **软删除**：聊天记录支持手动清除（DELETE），不保留回收站（隐私优先）
