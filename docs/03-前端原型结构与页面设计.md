# LanChat 前端结构与页面设计

> 文档版本：v3.0 | 更新日期：2026-07-31 | 状态：✅ 已完成

---

## 一、页面路由

| 路径 | 组件 | 说明 |
|------|------|------|
| `/` | DeviceList.vue | 主界面：设备列表 + 最近联系人 |
| `/chat/:ip` | ChatWindow.vue | 聊天详情页（一对一聊天） |

---

## 二、主界面 — DeviceList.vue

### 布局

```
┌─────────────────────────────────┐
│ 📡 局域网设备                    │  ← TitleBar（蓝色）
│ ┌─────────────────────────────┐ │
│ │ ⚙ 设置按钮    [扫描中...]    │ │  ← 顶部操作栏
│ ├─────────────────────────────┤ │
│ │ ┌─────────────────────────┐│ │
│ │ │ 🖥 我的设备               ││ │  ← MyDeviceCard
│ │ │ 用户名 | 本机IP          ││ │
│ │ └─────────────────────────┘│ │
│ │                             │ │
│ │ [📱 在线设备 ③]             │ │  ← 区域标题
│ │ ┌─────────────────────────┐│ │
│ │ │ 🟢 设备名   设备IP       ││ │  ← DeviceCard（可点击进入聊天）
│ │ │    💬 发消息            ││ │
│ │ └─────────────────────────┘│ │
│ │ ┌─────────────────────────┐│ │
│ │ │ 🟢 另一台电脑 192.168... ││ │
│ │ │    💬 发消息            ││ │
│ │ └─────────────────────────┘│ │
│ │                             │ │
│ │ [🕐 最近联系人]             │ │  ← 区域标题（5秒刷新）
│ │ ┌─────────────────────────┐│ │
│ │ │ 👤 用户名  ·  最后一条... ││ │  ← 联系人条目
│ │ │   刚刚                   ││ │
│ │ └─────────────────────────┘│ │
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

### 核心功能

| 功能 | 说明 |
|------|------|
| UDP 设备发现 | 自动扫描页面顶部有扫描动画，10秒超时 |
| 在线设备列表 | 设备卡片显示在线状态（绿点）和点击"发消息"按钮 |
| 最近联系人 | 从 contacts 表查询，`setInterval` 每 5 秒自动刷新 |
| 设置按钮 | 打开 SettingsDialog，修改用户名 |

### 交互行为

1. **点击设备卡片** → `await chatStore.openChat(ip, name)` → 先去数据库加载消息 → 再跳转到聊天页
2. **点击联系人** → 同上（联系人也是设备 IP）
3. **收到新消息** → 自动刷新联系人列表
4. **提示音** → 由 App.vue 全局订阅（不在本页面单独处理）

## 三、聊天窗口 — ChatWindow.vue

### 布局

```
┌─────────────────────────────────┐
│ ← 返回  用户名（设备IP）         │  ← TitleBar（白色 + 底部线）
│ [断开连接]                        │  ← 断联时显示橙色横幅
├─────────────────────────────────┤
│ ┌─────────────────────────────┐ │
│ │                             │ │  ← 消息区域（可滚动）
│ │  对方消息（左对齐 灰色气泡）  │ │
│ │                               │ │
│ │      自己消息（右对齐 蓝色气泡）│ │
│ │      待接收                   │ │  ← 失败消息状态提示
│ │                               │ │
│ │      发了一张图片 [📷 图片]    │ │
│ │                               │ │
│ └─────────────────────────────┘ │
├─────────────────────────────────┤
│ [🖼] [📎]                        │  ← 工具栏
│ ┌────────────────────┐  [发送]  │
│ │ 输入消息...          │         │  ← ChatInput（可拖拽拉高）
│ └────────────────────┘          │
└─────────────────────────────────┘
```

### 核心功能

| 功能 | 说明 |
|------|------|
| 消息显示 | MessageBubble 组件渲染，自己蓝色右对齐，对方灰色左对齐 |
| 进入定位 | `watch(messages.length, scrollToBottom, { immediate: true })` → 始终看到最新 |
| 状态跟踪 | pending→"发送中"，failed→"待接收"，sent→"已发送" |
| 图片预览 | 点击图片弹出 ImagePreview 弹窗 |
| 右键删除 | 右键消息气泡 → 确认删除 |
| 输入栏 | ChatInput 支持多行 + 底部手柄拖动拉高 |
| 图片输入 | 工具栏按钮选文件 / Ctrl+V 粘贴 / 拖拽文件到输入区 |

### 组件树

```
ChatWindow.vue
├── TitleBar (color="white")
├── MessageBubble (v-for)  ← 每条消息一个
├── ImagePreview (v-if)
└── ChatInput
```

## 四、Vue 组件清单

| 组件 | 文件 | 用途 |
|------|------|------|
| TitleBar | `src/components/TitleBar.vue` | 自定义标题栏，支持 `color` prop（蓝色=主页/白色=聊天窗），可拖拽，返回按钮可点击 |
| MyDeviceCard | `src/components/MyDeviceCard.vue` | 顶部显示本机信息（用户名 + IP） |
| DeviceCard | `src/components/DeviceCard.vue` | 在线设备卡片，绿点状态 + "发消息"按钮 |
| MessageBubble | `src/components/MessageBubble.vue` | 消息气泡：左右对齐、状态标签、图片懒加载 |
| ChatInput | `src/components/ChatInput.vue` | 输入栏：多行输入 + 底部拖拽手柄 + 图片工具 |
| ImagePreview | `src/components/ImagePreview.vue` | 图片预览遮罩层 |
| SettingsDialog | `src/components/SettingsDialog.vue` | 设置弹窗（修改用户名） |
| EmptyState | `src/components/EmptyState.vue` | 空状态提示 |

## 五、设计规范

| 要素 | 值 |
|------|-----|
| 主题色 | `#409EFF`（蓝色系，Element Plus 默认） |
| 卡片 | 圆角 12px + box-shadow + padding 16px |
| 消息气泡（自己）| 蓝色背景 #409EFF，白色文字，右对齐，圆角 12px 12px 4px 12px |
| 消息气泡（对方）| 灰色背景 #F0F0F0，黑色文字，左对齐，圆角 4px 12px 12px 12px |
| 消息状态标签 | pending=灰色"发送中"，failed=橙色"待接收"，sent=绿色"已发送" |
| 标题栏高度 | 主界面 40px（蓝底），聊天窗 44px（白底+底部线） |
| 窗口尺寸 | 开发模式 1000×650，拖拽调整不受限 |
| 窗口样式 | `frame: false`（自定义标题栏），`titleBarStyle: 'hidden'` |

## 六、前端工具模块

### ipc.js

```javascript
// IPC 封装：统一调用 + 错误处理 + 日志
import { call, eventApi } from '@/utils/ipc'

call('invoke:send-message', { targetIp, content })  // invoke 调用
eventApi.on('on:message-received', callback)         // 事件订阅（返回取消函数）

// 模块化接口
deviceApi.startDiscovery() / stopDiscovery() / connect(ip, port) / disconnect(ip)
chatApi.sendMessage() / sendImage() / getHistory() / getAllMessages() / deleteMessage() / getRecentContacts() / getUnreadCount()
userApi.get() / set(name)
imageApi.select() / getPath(relativePath)
```

### notification.js

```javascript
// Web Audio API 合成提示音（无需音频文件）
import { playNotificationSound } from '@/utils/notification'
// 在 App.vue onMounted 中全局订阅 on:message-received
```
