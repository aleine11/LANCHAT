# LanChat 前端原型结构与页面设计文档

> 版本：V1.0 | 日期：2026-07-30 | 风格：LocalSend 卡片设备列表 + 微信气泡聊天

---

## 一、前端文件夹结构

```
src/
├── main.js                       # Vue入口，挂载App
├── App.vue                       # 根组件，管理主窗口/聊天窗口切换
│
├── router/
│   └── index.js                  # 路由：设备列表(/) / 聊天窗口(/chat/:ip)
│
├── stores/                       # Pinia 状态管理
│   ├── device.js                 # 在线设备列表、发现状态
│   ├── chat.js                   # 当前聊天、消息列表、连接状态
│   └── user.js                   # 当前用户配置、主题色
│
├── views/
│   ├── DeviceList.vue            # 主界面：LocalSend风格设备卡片列表
│   └── ChatWindow.vue            # 聊天界面：微信风格聊天窗口
│
├── components/
│   ├── DeviceCard.vue            # 设备卡片组件（头像+名称+IP+状态指示灯）
│   ├── MyDeviceCard.vue          # 自己的设备卡片（顶部横幅）
│   ├── MessageBubble.vue         # 聊天气泡（文字/图片，左右区分）
│   ├── ChatInput.vue             # 底部输入栏（输入框+表情+图片+发送按钮）
│   ├── ImagePreview.vue          # 图片大图预览弹窗
│   ├── SettingsDialog.vue        # 设置弹窗（修改名称、主题等）
│   ├── EmptyState.vue            # 空状态提示（扫描中/无设备）
│   ├── TitleBar.vue              # 自定义标题栏（窗口拖拽、关闭、最小化）
│   └── SystemTray.vue            # 系统托盘提示
│
├── assets/
│   ├── styles/
│   │   ├── variables.scss        # CSS变量（主题色、圆角、阴影等）
│   │   ├── global.scss           # 全局样式重置
│   │   ├── animation.scss        # 动画（呼吸灯、弹入弹出等）
│   │   └── chat-bubble.scss      # 聊天气泡专用样式
│   ├── icons/                    # SVG图标（设备、图片、设置等）
│   └── images/                   # 默认头像等
│
└── utils/
    ├── ipc.js                    # IPC通信封装，统一管理主进程调用
    ├── time.js                   # 时间格式化工具
    └── validator.js              # 输入校验工具
```

**页面元素：**
1. **自定义标题栏**：Logo + "LanChat" 文字 + 设置按钮 + 最小化/关闭按钮（无边框窗口）
2. **我的设备卡片**：显示自己的头像图标、名称、IP、在线设备统计
3. **设备卡片网格**：每张卡片包含：
   - 状态指示灯（绿色呼吸灯 = 在线 / 灰色 = 离线）
   - 设备图标
   - 设备名称
   - IP地址
   - "开始聊天" 按钮（点击跳转到聊天窗口）
4. **空状态**：扫描动画 + "正在搜索局域网设备..." / "未发现其他设备"

**交互逻辑：**
- 打开软件自动开始 U盘广播 + 监听
- 点击设备卡片 → 跳转路由 `/chat/ip地址`
- 设备上线 → 卡片飞入动画
- 设备离线 → 卡片变灰 + 渐隐动画
- 设置按钮 → 弹出设置弹窗

### P2：聊天窗口页

**设计风格**：微信聊天气泡风

```
┌─────────────────────────────────────────────┐
│  ← 返回    小红电脑  🟢在线    ─   ✕       │
│  标题栏                                    │
├─────────────────────────────────────────────┤
│                                             │
│   ───────── 2026-07-30 10:30 ─────────      │  ← 时间分割线
│                                             │
│              ┌──────────────────┐           │
│              │ 你好，在吗？      │           │  ← 对方消息（左对齐，白色气泡）
│              └──────────────────┘           │
│                                              │
│  ┌──────────────────────────────┐           │
│  │ 在的，我看到你的设备上线了！   │           │  ← 自己消息（右对齐，蓝色气泡）
│  └──────────────────────────────┘           │
│                                              │
│              ┌──────────────────┐           │
│              │ 帮我看看这张图？   │           │
│              │ ┌──────────┐     │           │
│              │ │  [缩略图] │     │           │  ← 图片消息（可点击预览）
│              │ └──────────┘     │           │
│              └──────────────────┘           │
│                                              │
│  ┌──────────────────────────────┐           │
│  │ 收到！我看看                   │           │
│  └──────────────────────────────┘           │
│                                              │
│                                             │
│  ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄  │
│  😊 │ 输入消息...              │ 🖼️ │ 发送 │  ← 输入栏
│     │                         │      │      │
└─────────────────────────────────────────────┘
```

**页面元素：**
1. **聊天标题栏**：返回按钮 ← 、对方设备名、在线状态指示灯、窗口控制按钮
2. **消息列表**（可滚动）：
   - 时间分割线（跨天或超过5分钟间隔时显示）
   - 对方消息气泡：左对齐、浅灰色底、圆角左侧小尖角
   - 自己消息气泡：右对齐、科技蓝底白字、圆角右侧小尖角
   - 图片消息：缩略图（200x200px 限制）+ 点击可放大
   - 图片加载中占位图
3. **输入栏**：
   - 表情按钮（😊）— 第一期留位，功能第二期实现
   - 文字输入框（多行自适应，最大4行）
   - 图片选择按钮（🖼️）
   - 发送按钮（主色调圆角按钮）
4. **滚动到底部**：新消息自动滚动，手动上翻后显示"新消息↓"按钮

**交互逻辑：**
- 打开聊天窗口自动加载历史记录（分页，每次20条）
- 向上滚动加载更多历史消息
- 回车发送文字（Shift+回车换行）
- 点击图片按钮 → 打开系统文件选择器
- 支持 Ctrl+V 粘贴剪贴板图片
- 支持拖拽图片到窗口
- 点击缩略图 → 弹出大图预览
- 返回按钮 → 回到设备列表页
- 收到新消息 → 自动滚动到底部 + 未选中窗口时闪烁任务栏

## 五、页面状态覆盖

### 5.1 设备列表页

| 状态 | 条件 | 展示内容 |
|------|------|----------|
| 扫描中 | 刚启动，还没收到任何设备 | 旋转动画 + "正在搜索局域网设备..." |
| 空状态 | 扫描超过10秒无设备 | 插画 + "未发现其他设备" + "请确保：①同WiFi ②对方也打开了LanChat" |
| 有设备 | 发现至少1台 | 设备卡片网格 + 设备数量统计 |
| 对方离线 | 设备超时15秒无心跳 | 卡片变灰 + "已离线"标记 |

### 5.2 聊天窗口

| 状态 | 条件 | 展示内容 |
|------|------|----------|
| 连接中 | 点击聊天后TCP建立中 | 顶部显示"正在连接..."旋转图标 |
| 已连接 | TCP连接成功 | 在线指示灯变绿 + 聊天就绪 |
| 连接失败 | TCP连接被拒或超时 | 顶部红色提示条"连接失败，对方可能已离线" |
| 加载历史 | 向上滚动触发 | 顶部加载动画 + "加载中..." |
| 无更多历史 | 已加载全部记录 | "没有更多消息了" |
| 空聊天 | 第一次聊天 | 中间显示"你们还没聊过天，发送第一条消息吧~" |
| 图片发送中 | 正在传输图片 | 缩略图位置显示进度条 |
| 图片发送失败 | 网络中断 | 红色感叹号标记 + "发送失败，点击重试" |

### 5.3 设置弹窗

| 状态 | 条件 | 展示内容 |
|------|------|----------|
| 正常 | 打开弹窗 | 显示当前配置 |
| 修改中 | 编辑名称 | 实时显示字符数 1-20 |
| 校验失败 | 名称为空 | 红色提示"名称不能为空" |
| 保存成功 | 调用成功 | Toast "设置已保存" + 弹窗关闭 |
